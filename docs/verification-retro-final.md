# 0.2.0 改版验收

本页记录本轮九区生活控制台、五档作息、回复提交、记忆与管理的最终联合检查。
旧0.1报告、前轮失败与准备探针保留，不能作为本轮通过证据。

当前状态：本地最终回归、性能、合成页面与四版原生宿主验收完成。
仓库提交和远端CI由实际交付记录证明，不预填结果。

## 实现范围

- 米白、奶咖、淡绿与温润暗主题；点击中心圆形扩散，减少动效直接切换。
- TA 四维雷达、详细情绪、平台账号关系力图与0.1步进手动好感。
- 全局/私聊/群聊筛选，状态所有者与真实私密来源分离。
- 五档作息、固定精力100、0.1精度、持久赖床/骰点/回复轮数与绝对窗口。
- 晚安、完整分批补课、日记天气页头、梦境及带来源复核的置顶管理。
- LivingMemory 能力兼容、本地向量后端、分用途模型和集中设置。

## 本轮失败及修复

1. 两模式满载提交性能超过50ms。保留原失败报告，优化基础数据转换、
   数字校验与 SQLite worker 提交，未降低持久性、容量、样本或阈值。
   SQLite 页缓存由默认2MiB调整为有界16MiB，增加最多约14MiB工作集空间，
   WAL 自动检查点、FULL、正文与事件保留限制不变；实测结果另列。
   原无模式完整入口随后仍失败（52.250125ms、53.606125ms），均保留。
   后续将单连接固定到专用单 worker；取消仍先等待在途操作结束，
   关闭及初始化失败释放线程，调用者 ContextVar 按请求传播，不与其他后台工作共用。
   有限数检查保持子类、布尔与错误语义；去重与逐值校验合并扫描，不减少历史容量。
   继续保留55.441167ms、52.081916ms、55.922292ms、51.113917ms及50.573667ms
   的完整失败结果。后续将纯投影和JSON编码放在同一worker，已知原生快照单次转换，
   常规状态以原子UPDATE执行版本比较；自定义值回退原转换，日志仍同事务写入。
2. 四版宿主首轮均115通过/10失败，最后一版发现源漂移。该轮为初步 FAIL。
   已修正合成 Provider 重复注册、窗口用例时序、空 selection 和登录导航等脚本问题；
   产品修复原生 OpenAI embedding 模型读取及缺失时区后的 v2 状态保护。
3. 初始化失败时宿主可能不再调用终止钩子。Application 现在清理部分构建的
   服务、后台 worker 和 SQLite，不保留旧可写 API。
4. 原页面仅显示置顶。现接入同一认证 action、预期置顶状态和全记录事务比较；
   旧请求重放409，取消置顶不延长原日期或期限，模型调用和发送均为0。
5. 后续原生检查发现GENERAL_RESULT错误文本误扣回复精力。
   现在保留失败占轮，但不扣回复精力、不启动窗口；两类错误回归通过。
6. 原生页面脚本修正三处真实异步边界：正常关闭首次使用说明，
   置顶使用当前种子人格且等待状态/记录完成刷新，撤权覆盖先读的范围和模型选项。
   任一前置读取403后不再请求状态属于正确关闭式处理，不伪造成功响应。
7. 一轮4.29.2手机导航未生效，定向检查未复现，原失败保留。
   主题收尾改为取消填充动画并等待原生transition.finished；
   受控延迟完成反例验证旧实现会提前清除标记，新实现保持到浏览器完成。
   后续单版置顶回显竞态已由等待完整状态刷新修正，不以旧快照判结果。
8. 后续五次尺寸/主题往返压力用例再次暴露原生iframe漏点。
   子页面没有收到pointer事件，父页面收到以iframe为目标的点击；
   Dashboard侧栏在响应式切换时改变iframe偏移，子控件稳定不足以证明父布局稳定。
   验收脚本改为等待宿主有限动画结束、iframe几何连续四帧稳定及子页面两帧绘制，
   然后普通点击，不用force、重试或键盘替代。定向v4.29.3完整424项及
   163项浏览器检查通过，五次往返与36视图均成功；四版统一结果另列。
