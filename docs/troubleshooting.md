# 排障手册

适用0.4.3。读者：插件管理员和运维维护者。
2026-11-19按配置保存、运行守卫与原因码核对；每次发布及对应故障修复时更新。
先读取证据，不用重启或反复生成来掩盖原因。操作见[使用手册](user-guide.md)。

## 保存与版本冲突

1. 先核对页眉版本和当前人格/会话，确认从宿主插件页面进入。
2. 插件设置保存后看回执，再核对页面读回值；原生配置页按宿主提示应用/重载。
3. 409表示已有更新，重新打开设置读取最新版本，再修改目标项。
4. 磁盘值和页面运行读回不一致时先停改，核对加载实例、配置路径和生效来源。
   不用再次改更多键或重新覆盖文件“试试”。

页面自动刷新保留草稿，所以未保存草稿不等于当前运行值。版本、来源和保存回执要一起看。

## 睡眠关闭后仍显示低精力

0.4.3中关闭allow_sleep应立即清醒/100%，无时区也成立。
先确认当前实际加载版本、开关保存成功、页面选的人格/实例正确，以及是否仍显示旧草稿。
后台启动和配置替换应规范本实例全部存量夜间记录。
只改sleep时间、旧night_schedule_enabled或提示词开关不能代表关闭睡眠。
如果运行读回仍不符，保留现场检查相关状态/配置回执，不先重启丢失证据。

允许睡眠开启时，白天不回血、20%恍惚、0%困、固定沉睡满精力仍未醒都是可能的正常状态，
见[睡眠规则](sleep-energy-rules.md)。

## 主动聊天没发

按主动行为页面的原因逐项查：总开关、群额外许可、mode、真实目标、名单、
时区、静默、活动时段、免打扰、睡眠、冷却、未回应、额度、素材和Provider。
宿主主动任务启用且proactive_native_yield开启时会让行，这不是等待失效。
私聊名单空不授权；群号空覆盖全部已知真实QQ群，不能混用两者含义。
到随机检查时间不承诺必发。模拟无模型/发送；真实发送按钮仍有全部硬闸门。

## 日记或梦境没有文章

| 现象 / 原因 | 检查与处理 |
| --- | --- |
| 无可用素材 / material不足 | 核对同一真实会话与日期范围，正常互动后等评估；不会编造往事 |
| 模型不可用 / provider unavailable | 检查专用模型、通用模型、当前会话来源与类型；重新进入设置核对候选 |
| 输入预算超限 | model_input_tokens实际按UTF-8字节上界估计，太小放不下系统提示/人格；按配置参考核对 |
| 输出超限 | 正文最多2000字符，日记/梦境独立8192输出Token；上游可能有更小限制 |
| 自动梦境未睡够 / not_asleep | allow_sleep与dream_enabled都需开启，仍同周期睡眠且已睡满60分钟 |
| dream_requires_live_rem | 历史兼容原因码；当前自动规则按睡眠窗口/时长，不要求恰好REM |
| 身份/代际/素材授权失效 | 任务最终复核拒绝，旧结果不应写回；普通情绪更新不属于撤销 |
| 超时 / unknown | 不反复点击生成，先查任务/Provider请求状态；可能已经计费 |

自动日记关闭不禁止管理员手动日记；手动梦境仍需dream_enabled，
但无需当时睡眠。模型额度按尝试预留，失败不退款。
模型下拉框和状态刷新不同，新宿主候选可能需重新进入设置。

## 承诺排队、被拒或不重复发

先看promise_enabled、目标、时间、动作能力和任务状态；
当前承诺不占随机主动behavior_daily_limit，不能用该额度解释承诺停滞。
旧已有任务在关闭总开关后保留，但不兑现；重新开启仍按当前到期和最终守卫判断。
生成已成功时发送重试用原图；未知生成/发送停止自动重试。
图片内容规则拒绝后，要具体改人物/场景/风格或取消，“好的/再试”不算新画面。
多条任务先明确是哪条。

sent是宿主受理，unknown不是明确没送到。不能用cron摘要或after-sent钩子认定平台送达；
先看真实工具投递证据和reply_error/tool_call_failed记录，再决定后续操作。
详见[延迟动作](promise-actions-20261116.md)、[调整恢复](promise-adjustment-20261118.md)。

## 状态、记忆与权限

| 现象 | 含义 / 检查 |
| --- | --- |
| 新库空白/未采集 | 没有真实来源，不会随机造状态；选正确人格并正常互动 |
| 底气保持50% | 关闭情绪模型/无有效样本时中性正常，不代表四维不工作 |
| 关闭记忆仍有旧记录 | 读/写开关不删除历史；归档、关系、日记、承诺是不同存储对象 |
| 关闭提示词仍有情绪/生图拒绝 | 注入开关仅控制文本，领域状态与许可继续运行 |
| 关系无法编辑 | relationship_edit_enabled需保存开启，动作后端也检查 |
| 401/403 | 回宿主登录；页面资源token和客户端admin标记不能授权私人读写 |
| bridge缺失 | 从AstrBot插件页面入口访问，不直接双击HTML |
| 服务/存储unavailable | 留存结构化原因，先核对插件加载、数据库、当前实例与依赖 |

## 运维检查与回滚

更新前记录源码/配置SHA256、运行版本和关键许可；备份源码、原始配置和SQLite一致快照，
明确备份来源与回滚文件清单。逐文件比对，保留无关线上改动。
上线后检查插件版本、运行内存配置、监听、路由、数据库和新增错误。
读回矛盾先停止写入并单独取证；失败回滚目标文件，避免覆盖后续业务记录。
示例报告不能替代当前真实检查。通用维护依据见[独立运行](local-runtime.md)。
