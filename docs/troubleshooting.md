# 排障手册

适用0.6.0。按下面顺序核对，配置位置和默认值见[配置参考](config-reference.md)。

| 现象 | 核对与处理 |
| --- | --- |
| 状态为空 | 先确认有效原生人格和已有真实会话；新安装无历史属于正常空态 |
| 保存409 | 配置版本已变化；重新读取并核对草稿后保存 |
| 保存400 | 类型、范围或组合非法；时间不能形成空窗口，指定人格不能为空 |
| 始终清醒100% | 检查allow_sleep；关闭时就是这一行为，不因修改作息自动开启 |
| 开启后不按时间睡 | 配置有效IANA时区；只有调度创建周期，页面读取不创建 |
| 主动不发送 | 检查active、总/群许可、真实来源名单、时段、静音、安静时间、额度、未回应及宿主让行 |
| 模拟有内容但没消息 | 页面测试调用模型、写模拟日志，真实发送为0；preview才是不调用模型 |
| 手动日记无素材 | 可以自省；自动日记与手动生成准入分开 |
| 梦境按钮不可用 | 手动梦境仍需dream_enabled、可用人格与模型；自动梦境另需同睡眠周期和时长 |
| 承诺超过最近十条 | 任务完整显示，日志只显示最近十条；两者条数无关 |
| 图片失败后仍待办 | 查看明确失败、需调整还是结果未知；未知不能重画或直接取消掩盖 |
| 已发图又说没发 | 核对LH2.9.0的持久回执、同来源人格与LE原事项结算；prepared不代表发送 |
| 内容拒绝未自动调整 | 检查LH映射与重试上限、LE承诺动作能力；场景变化需用户确认 |
| 取消整体被拒绝 | 组内有运行中、未知、找不到或不唯一项；系统不会部分取消 |
| 缓存超时仍引用旧事实 | 兑现片段TTL与LH七天图片回执是不同记录；送达事实不代表用户已读 |

## 当前图片管理接口限制

`emotion-image-save`已注册，但当前PageAPI找的`console_emotion_image_save`
没有实现挂接；HTTP上传/删除可返回503。路由存在不能视为写入可用。
`emotion-image` GET query的index只接受2–6；首槽请省略index，显式1可返回400。
这两项是已核对的实现限制，当前手册不宣称页面上传与首槽显式读取已验证。
完整接口和错误格式见[API](api.md)。

## 判断模型与发送故障

依次查生效Provider、请求发起方、备用链路和运行配置。请求派发前可选择备用；
未知/可能已计费请求不自动换Provider再发。不要用重新启动清掉尚待核对的内存状态。
日志与回执只说明已观察阶段，不能把本地接受、宿主受理和平台最终送达混为一谈。
