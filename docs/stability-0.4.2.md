# 0.4.2 使用与边界说明

在插件提示词设置中选择预置、编辑或重置，并保存。各功能开关保持平铺，关闭后不注入对应请求内容。完整共享编辑衔接使用 LivingHello 2.7.11 与 `livinghello.shared-prompts.v1`。

插件独立 LLM 挂钩保留；未接入 LH 时仍可使用自己的预置。升级不重置人格、预置、自定义文本、关系或 SQLite 承诺数据；缺少的新字段使用默认值。

公共消息提交接口返回布尔值，内部详情另存；拒绝不代表提交成功。承诺重复交接保留历史重试次数，关闭承诺注入时请求中没有承诺提示。并发状态证据压缩后，200 个不同关系的输入均受理。

浏览器验证为假数据与本地接口，不能代表真实模型发送或计费链路已实测。
