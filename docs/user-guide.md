# LivingEmotion 使用手册

适用 **0.4.3**，AstrBot 4.29.1–4.29.4、Python 3.12及以上。
读者：使用插件的管理员。维护：AKIhunter；2026-11-19按配置、运行入口与离线回归核对。
参数细节看[配置参考](config-reference.md)，计算看[原理示例](principles-examples.md)，
接入看[技术说明](technical-guide.md)，故障看[排障](troubleshooting.md)。

## 第一次使用

1. 按[安装说明](installation.md)加载插件，从AstrBot插件页面打开 `livingemotion`。
2. 进入「设置 → 快速开始」，选择人格方式。「跟随」使用聊天当前人格；
   「指定」需同时选中人格；「不使用」不追加人格。人物性格预置是可选补充。
3. 情绪强度先选「平常」。本地规则情绪不需要模型，情绪模型、主动聊天、
   自动日记和梦境可先保持关闭。
4. 希望角色睡觉时开启「允许 TA 睡眠」，填IANA时区（如 `Asia/Shanghai`），
   核对夜间与午休时间。不希望睡眠影响聊天时关闭，精力立即固定100%。
5. 保存后返回TA，选正确的人格和会话。新安装没有真实互动时显示空态正常；
   正常聊天后状态自动刷新。

插件设置保存会更新运行配置，通常无需重启整个AstrBot。原生配置页则按宿主提示应用
或重载，再回插件页核对。直接编辑磁盘文件不代表运行内存已更新。
保存冲突（409）时重新读最新值再改；不要反复提交旧草稿。

## 页面与日常操作

| 页面 | 用途 |
| --- | --- |
| TA / 情绪 | 查看当前角色状态、五轴雷达、情绪曲线；对方观察与Bot心情分开 |
| 关系 | 搜索账号、查看好感与相处描述；编辑需先打开好感编辑开关 |
| 长夜 | 看精力、睡眠、唤醒剩余轮数、曲线与事件；设置作息 |
| 主动行为 | 查看主动机会、承诺、目标与失败原因；模拟和真实发送是不同操作 |
| 日记 / 梦境 | 分别查看正文、生成状态、来源、置顶；梦境是想象，不是事实 |
| 记忆 | 查看当前后端及读写能力；关闭开关不会删除已有数据 |
| 设置 | 各功能平铺开关、人格、模型、参数与预置提示词 |

全局视图用于汇总，不会创建发送目标。涉及生成/发送时选具体合法会话。
主题只改变页面外观，不改变作息。页眉插件名下显示版本，状态自动刷新保留未保存草稿。
生成和真实发送按钮会执行动作；「仅模拟」不调用生成模型、不发送。

## 全部功能开关

下面覆盖公开schema的 **32个布尔开关**。默认值指全新安装；升级保留已保存的显式值。
「设置」均指插件自己的页面；同名键也可在AstrBot原生插件配置中管理。
开启是允许执行，素材、人格、来源、模型、预算与最终守卫仍须满足。

### 插件、人格与情绪

| 开关 / 默认 | 开启控制什么 | 关闭效果 | 开启后去哪设置 / 使用前提 |
| --- | --- | --- | --- |
| `enabled` / 开 | 接入插件的状态、表达和已授权后台功能 | 停止插件业务执行；不删除历史 | 设置 → 快速开始；`mode=observe_only`仅观察，`active`参与表达与获许可的行为 |
| `persona_shared_state` / 开 | 同一人格跨会话共享情绪、精力数值 | 每个会话分别维护数值 | 设置 → 人格/生活状态；私人正文始终按真实来源隔离 |
| `emotion_model_enabled` / 关 | 使用模型异步细化四维情绪和展示用底气 | 保留本地规则情绪；底气不继续模型细化 | 设置 → 情绪/模型；配置聊天模型、间隔、静默时段和预算，会消耗模型额度 |
| `weather_factor_enabled` / 开 | 获取天气，影响四维回落目标 | 不再提供天气轮询目标和天气状态因子 | 设置 → 天气；填公开城市、核对时区/抓取窗口；不经过LLM |

### 主动聊天

| 开关 / 默认 | 开启控制什么 | 关闭效果 | 开启后去哪设置 / 使用前提 |
| --- | --- | --- | --- |
| `autonomy_enabled` / 关 | 随机等待后评估是否主动联系，包括群主动的总许可 | 不执行本插件随机主动发送 | 设置 → 主动行为；填写私聊QQ/群号、时区、模型、活动时段与额度，先有真实聊天来源 |
| `group_autonomy_enabled` / 关 | 在总许可开启时，额外允许群内主动发言 | 不执行群主动；不关闭已许可的私聊主动 | 设置 → 主动行为；群号留空覆盖全部已知真实QQ群，限定少数群时先填群号 |
| `proactive_native_yield` / 开 | 检测到宿主主动聊天任务时暂停本插件随机主动，避免两边重复 | 不因宿主同类任务让行，两套规则各自运行 | 设置 → 主动行为；如需要本插件接管，先核对宿主主动任务；此项不关闭承诺 |
| `behavior_emotional_share` / 开 | 在熟悉且合适的私聊中把轻微心情作为候选话题 | 排除分享心情动机，其他主动动机保留 | 设置 → 主动行为；仍需总许可、好感/信任/边界与合法素材，不用于群聊 |

主动私聊空号码名单不授权；群号空名单的含义不同。静默范围优先于允许范围。
到达随机时间只是再次评估，不保证准点发言。未回应、睡眠、冷却、免打扰、
额度不足、宿主让行或没有新素材都可能跳过，详情看主动行为页的原因。

### 睡眠、精力与晚安

| 开关 / 默认 | 开启控制什么 | 关闭效果 | 开启后去哪设置 / 使用前提 |
| --- | --- | --- | --- |
| `allow_sleep` / 开 | **唯一睡眠与自动作息总许可**；按精力、夜间、午休与补觉规则运行，允许手动入睡 | **立即清醒，精力始终100%**；回复和时间不扣减，不自动入睡/午休/补觉，不发睡前晚安；手动入睡拒绝 | 设置 → 长夜 → 自动作息；填有效时区、作息时间；关闭不需要时区 |
| `nap_enabled` / 开 | 总睡眠许可开启时使用计划午休时段 | 不执行计划午休；夜间与低精力补觉仍保留 | 设置 → 长夜 → 作息时间；设置午休起止，满精力不进入午休 |
| `energy_daytime_recovery_enabled` / 关 | 非疲劳时段未睡眠也按恢复速度增加精力 | 清醒、恍惚、困默认不回血；睡眠中仍恢复 | 设置 → 长夜 → 精力与清醒；设置每分钟恢复，不改变总睡眠许可 |
| `recovery_follow_wake_at` / 开 | 新补觉周期截止取下一次基础起床＋本周期赖床 | 新周期改用补觉最长时长 | 设置 → 长夜 → 精力与清醒/作息时间；只影响新补觉周期，固定夜间沉睡优先 |
| `closing_enabled` / 关 | 睡前向近期实际参与的真实会话评估发送晚安 | 不发送本插件睡前晚安 | 设置 → 长夜 → 收尾；设置提前分钟数，另须睡眠总许可、active模式和发送守卫 |
| `closing_random` / 关 | 晚安启用时调用模型生成随机文案 | 晚安使用本地模板；不关闭晚安功能 | 设置 → 长夜 → 收尾/模型；选晚安模型和预算，会产生模型调用 |

允许睡眠关闭后会规范本实例全部存量夜间状态，包含冷门会话。
再次开启更新计时起点，不补扣关闭期间的精力。编辑时区、作息、午休和赖床仅保存参数，
不会偷偷开启睡眠。旧 `night_schedule_enabled` 不再展示或作为运行时许可。
手动叫醒不增加精力；`le_wake`仅供已认证管理员，前缀以宿主配置为准。

### 醒后阅读、补答与招呼

| 开关 / 默认 | 开启控制什么 | 关闭效果 | 开启后去哪设置 / 使用前提 |
| --- | --- | --- | --- |
| `catchup_enabled` / 开 | 睡醒后按真实来源阅读睡眠期间未读归档 | 不执行醒后归档阅读及依赖这份阅读的补答 | 设置 → 长夜 → 醒后阅读；需真实未读材料，读历史不等于向历史每条补答 |
| `catchup_reply_enabled` / 开 | 阅读成功后允许有限历史补答 | 可以读历史，但不生成该类补答 | 设置 → 长夜 → 醒后阅读；需阅读许可、补答模型和预算；招呼另有开关 |
| `wake_autocatchup_enabled` / 开 | 自然醒后无人说话也尝试处理有未读的会话 | 不自动启动这一轮；收到新消息时的醒后处理仍可运行 | 设置 → 长夜 → 醒后阅读；只处理该睡眠期真实未读，不群发空招呼 |
| `wake_greeting_enabled` / 开 | 合法醒后处理开始时，在阅读前发一句刚醒招呼 | 不发这句招呼；阅读/补答按自己的开关继续 | 设置 → 长夜 → 醒后阅读；编辑竖线分隔的招呼候选；不等于主动聊天总开关 |

想「只读不冒头」应关闭补答和招呼两个开关；仅关闭补答不会同时关闭招呼。

### 承诺、日记与梦境

| 开关 / 默认 | 开启控制什么 | 关闭效果 | 开启后去哪设置 / 使用前提 |
| --- | --- | --- | --- |
| `promise_enabled` / 开 | 识别明确延后的承诺，登记、扫描并兑现 | 既不新建也不兑现；已有记录保留 | 设置 → 承诺；设置扫描间隔、缓存与动作协作，旧上限参数未接入执行，见[配置参考](config-reference.md#承诺) |
| `diary_enabled` / 关 | 按本地计划自动生成私人日记 | 停止自动日记；管理员手动日记仍可使用 | 设置 → 日记/模型；填时区、日记时间、合法素材、模型与预算 |
| `diary_backfill_yesterday` / 关 | 自动日记启用时尝试补昨天缺失的一篇 | 不补昨天，只评估当天计划 | 设置 → 日记；不遍历更早日期，不保证缺失必补成功 |
| `dream_enabled` / 关 | 允许自动梦境，也允许管理员手动生成 | 自动和手动梦境都拒绝 | 设置 → 梦境/模型；自动需仍在同一段睡眠、未到起床且睡满60分钟；手动不要求睡眠 |
| `dream_owner_notify` / 关 | 自动梦境因愤怒或恐惧惊醒时，给主人尝试一次专用通知 | 不发送这类通知，梦境仍可生成 | 设置 → 梦境；填一个已有真实私聊的主人QQ；可能夜间发送，手动梦境不通知 |

即时能做的事当场执行，不建延后承诺。取消承诺只有一条时直接取消，多条需明确选择。
图片被内容规则拒绝后，具体调整画面才恢复，纯“继续/再试”不触发重复生图。
`sent`表示宿主受理，不证明平台最终送达；未知生成/发送结果不盲重试。
日记、梦境正文最多2000字，独立8192输出Token预算仍受上游限制。
正常情绪更新不使已选素材快照失效，身份撤销和清除代际会阻止迟到写回。

| --- | --- | --- | --- |
| `prompt_core_enabled` / 开 | 主回复注入共享通用、情绪和关系说明 | 省略这些说明；动态状态、关系数据和功能协议保留 | 设置 → 提示词注入 → 通用说明·预置；在人物性格编辑区下方展开查看 |

这些开关控制文本注入，不能用来绕过实际功能许可。关闭表达说明并不会关闭对应领域计算。
独立安装保留自己的LLM挂钩；完整共享提示词编辑使用LivingHello 2.7.11公开契约。
三项旧普通提示词若关闭且保持默认稿，控制台会省略对应编辑框；
需要启用时可先在AstrBot原生插件配置开启并应用，再回提示词页面编辑。
已启用或已有自定义稿的条目继续显示。全部32个开关指公开schema，不表示当前页面必有32个控件。

## 升级时需要知道

0.4.3把睡眠和自动作息合成一个总开关。显式 `allow_sleep` 优先；仅旧配置缺少该键时
从旧作息许可迁移一次。旧组合 `allow_sleep=true / night_schedule_enabled=false`
现在按允许睡眠运行，有效时区下自动作息也启用。这是合并的明确行为变化。
升级不覆盖既有耗能、作息、人格、模型、关系和数据库；历史默认值不能代替你的实际配置。

没有 `/livingemotion ...` 命令族。完整接入、迁移和兼容依据见
[技术说明](technical-guide.md)、[兼容矩阵](compatibility.md)。
