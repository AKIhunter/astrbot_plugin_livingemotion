# 使用手册

适用0.10.1，2026-11-26核对。每个开关的开启关闭效果、设置位置和用例见
[完整配置参考](config-reference.md)；本页说明实际操作。

## 开始使用与保存

打开 `livingemotion → 设置`。先选择跟随会话人格或指定原生人格；指定模式必须选有效人格。
通用后台模型可以留空跟随真实会话模型，各用途有独立模型覆盖。
模型下拉显示可读名称并随状态自动更新；保存仍使用原Provider ID。
规则情绪不需要模型；仅观察模式记录状态但不注入表达或主动发送。

配置按分区导航，但各功能开关平铺独立保存。修改后统一保存；页面自动刷新保留草稿。
保存前带当前配置版本；409冲突时重新读取并核对，失败项不应当作已保存。
原生AstrBot配置页与插件页编辑同一份配置。凭据在宿主模型管理页面设置。

## 新手引导

拿不准先配什么，点设置页顶部的「新手引导」，展开六步清单：人格、关系、长夜、提示词注入、风格摘要、模型选择。
每步一句话说明这项管什么、在哪里改，并标出「已配置」或「默认」；点「去设置」跳到对应分区并定位字段。
清单只读，不改任何配置，展开状态在自动刷新后保留。

「模型选择」一步列全 9 个模型项：默认生成、备用生成、情绪、主动行为、补课、收尾、日记、梦境和原生向量模型。
除原生向量模型外留空即跟随主模型；原生向量模型是另一类模型，只有本地向量记忆需要，留空即「未配置」。

## 导出诊断日志

点击页面顶部「导出诊断日志（近3天）」，管理员登录后通过宿主下载脱敏 ZIP。无需开启新配置，不调用模型；打包时按钮禁用，完成或失败后自动恢复。独立记录最多32 MiB，自动清理超过72小时的文件。范围、权限、失败提示及历史缺失说明见[诊断日志](diagnostics.md)。

## 看情绪与关系

TA和情绪页面自动更新。四维规则参与情绪计算，底气由模型写入并调节负面情绪和表达；
没有模型细化不等于没有规则情绪。愉悦、压力等状态表示当前角色数值。
在「设置 → 情绪」开启模型细化后，底气沿用联合分析更新；
关闭后旧值逐渐回到中性0.5。底气不改变事实依据、好感分或任务许可，
详见[掌控感](control-integration.md)。
开心窗口限制近5分钟正负变化，普通互动和合理纠错不自动加减开心。

TA 概览显示九项情绪谱，六项基础情绪来自当前人格。需要委屈、受伤、害羞时，
在「设置 → 情绪」开启独立开关并保存，把「工作模式」设为「参与表达与行动」，在 TA 页选择具体对象。
情绪按会话还是按人，在「设置 → 快速开始 → 对象情绪维度」选择：会话维度（默认）下各群和私聊各自独立；
用户维度下同一个 QQ 号共用一份，在群里受的委屈会带到私聊。关系、日记和记忆仍按会话隔离。
未采集显示未采集，真实零值显示0，不用其他对象的数据补齐。
仅观察模式不新增这三项采集。关闭开关停止采集与表达。
同页开启模型细化后，模型结合近期对话与语气判断变化；复用联合分析，
四维分析冷却时可补一次专用对象分析，共用每日额度，回复前最多等待1秒。
超时先回复，分析在后台完成并写回，下一次回复生效；模型不可用时只保留历史衰减。
关闭模型时沿用不调用模型的本地规则。
TA选择跨刷新保留，下拉最多10个候选；输入完整账号ID后回车优先定位私聊，
同账号多个群聊需明确选择。
详见[采集、有效期与情绪谱](ta-emotion-spectrum.md)。

关系页面按真实来源展示对象。开启「允许编辑关系」后管理员可校正分数、冻结、
备注及阶段名称。普通互动最高99；100分由管理员明确设置。
关系页只与TA共享人格，平台、搜索和页码独立保留。日列表每日本地00:00更新并按
精确好感度降序；首次启用或跨日停机后按当前时间补算。当天新对象可在实时3D看到，
次日进入日列表；3D详情和编辑始终读取实时值。详情隐藏信任/边界，底层字段保留。
阶段生图婉拒概率只判定新个人图片请求；已接受任务继续履行。
编辑时仍自动刷新列表，保留草稿和原保存版本；冲突后点击「读取最新关系并复核」，
核对草稿再保存，自动刷新不会替你接受外部修改。

## 作息与精力

在「设置 → 长夜」开启「允许 TA 睡眠」，设置时区、夜间、沉睡、基础起床和午休。
关闭立即清醒，精力始终100%，不睡眠、不补觉、不发睡前晚安；
保存时间、午休参数不会自动开启睡眠。

夜间未睡眠按分钟扣精力，首次有效回复提交扣一次；重复提交和分段不多扣。
每周期只抽一次赖床并保存。页面自动刷新只投影现有状态，不创建周期、不重抽。
聊天唤醒按私聊/原生@许可、轮数和固定窗口判断，固定沉睡不能靠普通聊天绕过。

长夜页「手动入睡」需要总开关和active模式；「手动叫醒」立即醒来，正常开启时保持原精力。
关闭睡眠时叫醒保持100%。自然醒后的爬楼、招呼和补答有独立开关；
只使用真实会话保存的未读，不读取平台全部历史。

## 主动聊天

在「设置 → 主动行为」填写已有真实QQ私聊号码并开启总许可；群聊还需独立群许可。
群号空值覆盖已知真实QQ群，私聊名单空值不授权。静默范围优先。
设置随机等待、安静时间、活动时段、免打扰、额度与未回应退避。
到机会只评估，条件不满足会等待。开启宿主让行时，仅同会话定时问候前后各15分钟暂停随机主动，
其他时段继续检查；设置位置与边界见[定时问候让行](native-proactive-yield.md)。

主动行为页显示时间到秒、发送ID、当时情绪、目标号码、内容与是否回应。
最近日志自动更新，历史情绪缺失时不会用当前情绪补填。
「preview」只算条件，不调用模型、不发送；「测试」使用所选情绪调用模型，
写模拟记录但不真实发送，可能产生模型费用。「真实发送」会请求模型并联系真实目标，
仍检查身份、静音、时段、额度和来源。
测试共12个选项：当前、平静、喜悦、悲伤、愤怒、恐惧、惊讶、厌恶、关爱、
委屈、受伤、害羞。无素材也可模拟；结果不写入正式情绪，重复同一请求不重复生成。
素材完成不代表已经提交、交付或确认；模拟按已有事实表达，掌控感只改变语气。

## 承诺与图片任务

开启承诺后，明确说稍后再做的约定登记；能即时完成的请求当场处理。
主动行为页显示全部未完成和暂停任务，数量不被「最近十条日志」截断。
卡片显示创建时间、执行时间或原定时间、发送目标和状态；展开看完整内容与原因，
自动刷新保留展开状态。

挂起上限在「设置 → 承诺代办」调整。等待调整、结果未知仍占名额；
满额拒绝新建，复用原任务不新增；降低上限保留已有记录。
到期独立执行，不需要用户再发一句。宿主定时任务接管同事项时LE让行。

LH生图工具可以带 `promise_id` 原子领取已接受事项，发送结果结算同一ID。
新图未带原事项ID不会清除其他任务。`prepared`仅准备，`generated`仅生成；
`sent`是发送接口受理。下一轮可读取成功回执，但回执不等于视觉检查或用户已读。

内容拒绝或超长描述可按LH映射策略，由LE自身模型有限调整等义词；
成功后局部词对按真实连接、模型、协议保存并复用。姿势或场景变化须用户确认。
用尽调整次数后询问调整或取消。未知生成/发送先核对，不能重新收费。
用户明确调整通过 `followup_id` 恢复原事项。聊天取消按短编号或唯一关键词定位，
多项取消全组核验；含执行中或未知结果的组整体拒绝，不留下部分取消。

## 日记与梦境

在「日记梦境」选择类型。手动「生成/重写」使用当前人格，不要求先有素材，
无素材可以自省或想象；不受自动日程和自动额度准入限制，但仍记录实际模型用量。
手动日记不需要自动日记开关；手动梦境仍需开启梦境生成。
自动日记按时间评估，自动梦境需要同周期仍睡眠且达到时长门槛。
正文最多2000字符，标题、日期和天气另计。

置顶用于保留未固定记录；取消置顶重新遵循保留期。测试与真实发送按页面说明区分。
摘要和记忆镜像不把主观日记、想象梦境变成事实；使用外部记忆需接口可用和独立读写许可。
配图管理接口的当前限制见[排障](troubleshooting.md)与[API](api.md)，路由注册不等于写入可用。

## 人物性格与提示词

在「设置 → 提示词注入」选择毒舌、可爱、温柔或自定义，分别保留编辑稿。
人物性格最多10000字符，开启时不能为空。通用说明位于人物性格下方，
默认折叠显示预置正文；普通提示词有独立开关，文本最多2000字符。
关闭保留文本，功能许可和动态状态由各自模块独立控制。

## 风格摘要

「设置 → 人格与状态模式 → 原生人格」下方的「LivingEmotion 风格摘要」只给本插件使用，
不改宿主人格；留空时使用原生人格前缀，点「恢复默认」同样清空。
点「用主模型自动填写」会按当前人格的设定调用一次主模型，写一份说话风格摘要，
可能产生模型费用；主模型就是「默认生成模型」，留空时用该人格最近一次真实会话的聊天模型，再退回备用生成模型。
生成不占每日额度，只记一条审计日志。生成的内容只填进输入框当草稿，必须再点「保存摘要」才生效。
输入框里有没保存的修改时，按钮会先变成「覆盖未保存的修改？再点一次」，再点一次才覆盖。
同一时刻只能生成一份；人格没有设定或设定超过16000字时不会生成。
失败时输入框内容不变，并按原因提示：模型没有返回正文时建议调大「模型输出上限」或换个模型，
等待超时提示可以重试，模型不可用或生成失败则提示没有生成草稿。

## 记忆与清理

开启LivingMemory接入后使用其公开接口；关闭走本地向量路径，需要有效embedding。
读取、写入分别授权，正文按原真实会话隔离，同人格共享只合并允许的数值状态。
清空操作改变代际，旧在途任务不能写回；重载不把未知请求认定为未执行。
升级前备份配置与SQLite一致快照，旧睡眠字段迁移边界见[配置参考](config-reference.md)。
0.7.0自动升级SQLite至v9，不回填旧历史掌控感，不重置关系或配置开关。
