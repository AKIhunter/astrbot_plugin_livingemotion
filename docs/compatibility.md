# 兼容性与验证边界

支持范围以 `metadata.yaml` 为准：AstrBot 4.29.1–4.29.4、Python 3.12 及以上，
插件版本 0.2.0，进程内 API v1。未测宿主或其改版不能自动视为兼容。

| 接点 | 支持行为 | 限制 |
| --- | --- | --- |
| 原生人格 | 跟随会话、指定人格、关闭人格 | WebChat 特殊人格路径不支持 |
| 本地状态 | 自身规则、数据库、作息与额度 | 其他情感插件开关不再触发退让 |
| 聊天模型 | 原生 `ProviderOpenAIOfficial` 与 router 指定上游 | 整体 router、任意第三方 Provider 不自动支持 |
| 向量模型 | 原生 OpenAI / DashScope | 更换模型后不跨维度检索 |
| LivingMemory | 当前公开授权、关系和事件接口 | 无权限返回空，不读取私有库 |
| 管理页 | Dashboard 管理员验证、API v1 | 资源令牌、query token、cookie-only、`admin=true` 不能授权 |
| 回复记录 | 原生最终输出记为“已提交” | 不证明平台送达；未知发送不自动重发 |
| 页面主题 | 自有资源、自动刷新、双主题 | iframe 禁持久化时主题仅本次有效 |

输入预算采用完整 UTF-8 字节数加 256 模板余量，不是精确 token usage。
默认输入上限 32768、输出 1024、并发 1、队列 100、每日模型调用 48、超时 30 秒；
router 自身可设置更小输出或超时上限。两种模型路径均为纯文本。

原生回复确认不可用时不制造 receipt；收尾最多 120 秒后取消，
无待回复的计划睡眠和手动睡眠可用。天气不可用显示“未获取”。
后台授权与幂等体验导出缺能力时拒绝，开关不能赋予能力。
