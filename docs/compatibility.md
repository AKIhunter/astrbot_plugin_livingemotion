# 兼容性与验证边界

适用0.6.3。metadata限定AstrBot 4.29.1–4.29.4，声明范围不代替各环境真实验收。

| 路径 | 当前支持与边界 |
| --- | --- |
| 独立情绪、关系、作息、精力、主动行为 | 插件自己实现；按observe_only/active等实际模式执行 |
| LH协作 | 公开能力与同事件契约；原事项回执完整链路配套LH 2.9.0 |
| LivingMemory | 可选公开接口；后台检索或幂等导出能力不足时unsupported |
| 管理页面 | Bearer管理员身份、校验与CAS；资源token或客户端身份参数不授予管理权 |
| 普通回复确认 | 宿主after-sent和布尔值不能证明平台送达，reply_confirmation可能unavailable |
| 待回复settling | 无可靠确认时保留120秒回退保护；计划/手动睡眠单独可用 |
| 情绪配图保存 | 路由存在，应用层入口缺失，当前503 |
| 人格共享 | 状态共享不放宽账号、私人正文、路由或素材授权 |

离线规则和合成浏览器通过只证明相应路径。真实宿主分层、models预检、
计费模型内容效果、真实平台投递与生产峰值必须分别验证。
历史宿主失败和布局结果见[更新日志](../CHANGELOG.md)，不拿旧报告当当前代码通过。
接口与已知缺口见[API](api.md)，可复测命令见[检查分层](delivery-notes.md)。
