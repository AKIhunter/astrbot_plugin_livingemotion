# 独立运行与存量升级

适用0.9.0。核心情绪、关系、作息、精力、补答、许可与预算由LE自身实现，
不依赖旧外部情感库，不读取另一插件私有配置。LH、LM为可选公开协作接口。
设置说明见[使用手册](user-guide.md)。

| 升级内容 | 存量处理 |
| --- | --- |
| 公开配置新增缺省值 | 保留已有显式数值，Config兼容加载 |
| night_schedule_enabled退役 | allow_sleep唯一授权；不继续显示旧开关，不靠时间参数授权 |
| 关闭睡眠 | idle/shared记录与票据归一，清醒100%；重开只算开启后的时间 |
| 生图原事项绑定/结算 | SQLite补兼容字段，原ID、状态与额度保留 |
| 提示词有限调整 | 原action_result保存候选、原文和计数；旧任务按零次预算兼容 |
| 未知图片副作用 | 暂停核对；不能升级后再生成或补发 |
| 本地向量模型变化 | 校验维度/指纹，必要时重建；不拿旧索引冒充兼容 |

备份必须包含配置、源码和一致SQLite快照，并记录逐文件SHA-256。
升级后核对加载、实际配置读回、能力和日志；失败按指定文件回滚，
不能拿旧整库覆盖新产生的记录。默认值不等于生产已变更值。
接口见[API](api.md)，实现见[技术说明](technical-guide.md)。
