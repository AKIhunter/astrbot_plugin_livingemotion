# 日记、梦境与素材

适用0.6.0。入口：“日记与梦境”，设置位于同名设置组；
自动任务、手动任务与同步结果分别显示，页面自动查询任务进度。

## 自动与手动生成

自动日记需diary_auto_enabled、时间到达、许可和有效模型；
自动梦需dream_enabled、作息与素材条件。
失败最多diary_retries配置的0–2次，自动预算由model_daily_calls等控制。
手动日记作管理员私人自省，手动梦作想象，即使没有素材也可生成；
手动梦仍要求dream_enabled，不要求REM或睡眠时长。
手动任务不受自动时机、次数限制，但仍记用量并可能产生模型费用。

手动生成使用experience-generate的稳定request_id；同ID复用，
同人格当日同类型正在运行时返回已有ID，页面轮询返回的ID。
重载只查询、不重新生成。配置中的日记/梦境模型优先，再按用途模型链选择。
实际预检要求同一上游models接口5秒内返回200，才派发正文；
预检失败记录受控原因，旧手动成功不能覆盖自动失败状态。

## 预算与正文

手动输入上界32768 UTF-8字节，输出请求8192 Token、90秒超时；
正文最多min(2000, experience_body_chars)字符。字符、字节和计费Token是三种量纲。
自动任务另受配置预算与重试限制。模型替身测试不证明真实费用或内容质量。
梦的配图、表情素材和日记正文各自遵守许可，素材失败不伪造发送。

成功替换当日同类正文并保留置顶，失败保留旧正文；
自动任务不覆盖当天手动修订。来源、清晰度、是否可同步与生成状态分开记录。
置顶冻结当前清晰度并免于普通遗忘清理，取消置顶按原创建日计算期限。
跨人格、撤销来源、清除代际仍阻挡迟到写回；正常情绪/作息更新不丢弃已捕获材料。

## 私人来源与分享

正文保留真实source_ids与授权，不作为新的人类刺激。
私人日记/梦仅在LE档案；memory_sync=skipped_private_archive，
成功生成不等于同步到LivingMemory。主动分享要通过自己的目标、许可及发送守卫，
手动生成不会顺手发送。未经确认的上游或发送结果记unknown，不盲目补发。

情绪配图读取可用，但当前emotion-image-save缺应用入口返回503；
API记录该缺口，不能把注册路由当作保存已接通。
操作见[使用手册](user-guide.md)，21项管理端点见[API](api.md)。
