# 主动记录与自动体验修复

修复自动日记、梦境因临时消息来源失效而无法入队的问题，并补全控制消息与合并晚安的历史记录。

- 控制发送在生成前采集情绪标签，正文和情绪随发送意图落库。合并晚安只记录自己的文本，没有可信平台回执时仍为未知。
- 额度占用、确认、未知、取消、失败和处理中分别统计；发送日志与汇总自动刷新，搜索框聚焦不暂停。
- 自动私有生成复核登记身份、当前人格、配置、模型、素材、水位及清空代次；没有实时来源时只用已入库的本地素材，消息投递仍使用原实时校验。
- 每人格选最近会话调度，保留到点生成、睡满一小时、补昨天、每日去重、重试和手动内容保护。
- 情绪历史保存采样时的动态基准，日记情绪读取也保留该基准。数据库版本 7 → 8；旧样本缺失的基准不补造，页面明确提示。

每日全局 6 次、单会话普通主动 2 次仍是上限，不保证发满。真实喜悦跃升的规则和模型计算保持原样，本次只修正历史投影基准。

本地全量实测：修改前 1692 通过、28 失败；修改后 1715 通过、同样 28 项失败；新增 23 项全部通过。浏览器 1440、390、320 三种宽度验证通过，无真实模型消费或消息投递。

回归入口：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv-ci/bin/python -m pytest tests -q -p no:cacheprovider
node tests/ui/send-status-browser.test.mjs
```

新增测试位于 `tests/experience/test_restart_private.py`、`tests/storage/test_emotion_baseline.py`、`tests/storage/test_send_statistics.py` 和 `tests/ui/send-status-browser.test.mjs`。控制与合并发送测试分别扩展于 `tests/behavior/test_behavior.py`、`tests/integration/test_retro_closing.py`。

部署须先备份目标文件、配置和一致性数据库快照，再逐文件核对 SHA-256。版本 8 数据库不能直接交给旧代码，回退时需恢复对应数据库备份或采用已验证的兼容降级。
