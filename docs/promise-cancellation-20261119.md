# 承诺取消修复（LE issue #1）

取消标记兼容标准冒号、全角冒号、缺冒号和 `<  --` 注释开头。
`|`、`、`、英文逗号和中文逗号可以连接多个编号或关键词，也可使用至少八位的唯一 ID 前缀。

执行前先按当前会话完整列表定位全部目标，再在一个 SQLite 事务内复核状态并取消。
任何目标不存在、有歧义、已进入执行或结果未知，整组不写入。
已知的内容拒绝、接口失败、限流和额度耗尽可明确取消；未知生成和未知发送保留核对保护。

标记按完整正文的区间从各文本组件扣除，跨组件标记也不会暴露或复制正文，
图片及组件顺序保持原样。仍只在原发送确认链路通过后执行，日志记录状态和数量。
