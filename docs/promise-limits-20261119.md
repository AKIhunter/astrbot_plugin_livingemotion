# 承诺名额与注入修复（LE issue #5）

`promise_max_active` 默认 3，范围为整数 1–10。
schema、配置保存校验、运行时保护及 API 视图都读取同一配置值。

回复标记建立承诺与 LH 失败交接两个运行入口都把上限传入存储事务。
事务先做去重、同源复用，再计算本会话 scheduled / running / waiting / awaiting 数量；
满额返回 `limit_reached`。暂停项不会超时自动取消，降低上限不删除旧项。
完成或明确取消后才释放名额；原任务交接、恢复不额外占用名额。
底层存储允许省略限制，仅用于旧接口兼容及离线旧库播种，运行入口始终传限额。

管理与取消读取完整活动列表，计数使用 SQL COUNT，避免 20 / 200 条截断。
模型提示仅显示前三条，每条描述最多 96 字；暂停规则共用一份，
明确报告总数与展示数，不把未展示任务视为不存在，也不猜其编号。
本次保留原有即时生图许可与延迟承诺格式，没有引入真实模型请求。
