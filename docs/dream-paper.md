# 全局日记、梦境池与天气情绪

2026-11-09。天气同时作用于 TA 的日常情绪、正常回复语气和梦境定调。

## 使用

在「日记与梦境 → 设置」填写 Bot 所在城市、梦境主题池。
默认有 12 个主题：赛博朋克、绿野仙踪、生活日常、星际漫游、海底王国、
古堡奇遇、森林童话、校园时光、蒸汽幻想、云端旅行、四季庭院、时光回廊。
每行一个主题，也可粘贴 JSON 列表或用中文逗号分隔；去重后允许 2–32 项。
每个梦随机抽取两个不同主题。

手动「生成私人日记」「生成梦境」生成当天内容，成功后替换当天同类内容，
不受自动生成时间、启用开关或每日自动次数限制。手动梦境不会触发主人消息。
刷新只更新状态和列表，不生成内容；未知结果不自动重试。

页面统一使用全局人格视图；共享状态使用人格状态，拆分状态使用最近活跃会话的投影。
底层消息来源与授权隔离仍然保留。日记和梦境采用可展开的纸页，
仅显示标题、日期及正文，日记额外显示天气。页面不提供置顶、来源或修改原因输入框。
编辑后提示保存，保留版本冲突检查，操作原因由程序自动记录。

## 情绪如何决定梦

| 当日主导情绪 | 梦境表现 |
| --- | --- |
| 喜悦 | 明亮轻快的美梦 |
| 愤怒 | 冲突、委屈，可能生气惊醒并向主人诉说 |
| 悲伤 | 失落、离别，醒来眼角湿润 |
| 恐惧 | 噩梦，可能惊醒向主人求安慰 |
| 惊讶 | 大胆、荒诞、抽象的冒险 |
| 关爱 | 陪伴和温情 |
| 平静 | 简单安稳，整夜没有惊醒 |

主导情绪取六项数值中最高者；所有项目均低于 25% 时使用平静。
有当日历史时，用当日有效五分钟时段的平均值定调；没有历史时使用当前状态。
梦境正文由模型生成，上述表现是生成要求，不是对每篇自由文本的硬编码替换。

## 天气加成

| 天气 | 加成 |
| --- | --- |
| 晴、基本晴 | 喜悦 +20 个百分点 |
| 雨、毛毛雨、雨夹冻雨 | 悲伤 +20 个百分点 |
| 阴、多云 | 六种情绪各 +10 个百分点 |
| 雪 | 关爱 +40 个百分点 |
| 雷电、冰雹或可信灾害标记 | 恐惧 +25 个百分点 |

例如 30% 喜悦遇到晴天后为 50%，上限 100%。加成是可替换的每日数值层，
不反复写入底层四维状态，所以连续刷新不会叠加。
城市、日期、时区必须全部匹配；天气获取失败或未知类型不加成。
灾害优先于雪、雨、阴和晴。

当前 Open-Meteo 接口提供雷电、冰雹等天气代码，不提供可靠台风标签。
逻辑支持可信台风标记，但不会仅凭大风自行判定台风。

## TA 的六维曲线

「TA」直接展示近 24 小时的喜悦、愤怒、悲伤、恐惧、惊讶、关爱曲线。
共 288 个五分钟时段；鼠标悬浮显示时间和六项数值，也支持方向键、Home、End。

`emotion_samples` 只保存底层情绪数字，不保存聊天正文或人名。
状态写入和采样在同一个 SQLite 事务完成；历史按真实记录和已有自然衰减计算，
再应用对应日期的天气。没有记录的时段留空，不补造历史。
清空或切换状态代次后，旧代次数据不会作为新状态历史展示。

## 梦中惊醒消息

需要填写一个「主人QQ」并开启「梦中惊醒给主人发消息」，默认关闭。
只有当前夜间睡眠周期内保存的自动愤怒/恐惧梦可以触发；
午休、手动生成、已醒来、模式关闭、静默、主人修改、来源撤销、状态模式或代次改变均不发送。

必须存在合法、实时的 QQ 私聊来源，不从号码伪造发送路由。
同一人格、同一夜、同一主人最多形成一个发送意图；未知结果不重发。
消息使用简短诉说或求安慰文本，不把私人梦境正文发给第三方。
提交到宿主后进入约五分钟的惊醒窗口，按规则计精力，随后恢复睡眠；
只有取得可靠消息回执才确认发送成功。

## 代码位置

- `domain/dreaming.py`：主题解析、六情绪、天气加成、梦境表现。
- `services/experience.py`、`services/manual_experience.py`：自动与手动生成。
- `runtime/manual_experience.py`：当日情绪快照和正常回复使用的天气情绪。
- `runtime/console.py`、`storage/state_scope.py`：当前状态与五分钟历史。
- `runtime/night.py`、`services/behavior.py`：惊醒授权、同夜去重和可靠发送。
- `pages/livingemotion/charts/emotion.mjs`、`app.mjs`：曲线悬浮、纸页、全局视图与保存。
- `storage/schema.py`：schema 6 的纯数值历史表。
